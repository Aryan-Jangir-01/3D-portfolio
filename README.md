# ⚡ Aryan Jangir - Next-Gen Interactive Developer Portfolio

An ultra-modern, interactive, and futuristic developer portfolio engineered with **React 19, TypeScript, Tailwind CSS, Web Audio API, and HTML5 Canvas**.

## ✨ Features That Make It Unique

1. **🎨 5 Dynamic Cyberpunk & Sci-Fi Themes**:
   - `Cyber Neon` (Cyan & Electric Violet)
   - `Cyberpunk 2077` (Neon Yellow & Hot Pink)
   - `Matrix Hacker` (Phosphor Terminal Green)
   - `Synthwave 84` (Retro Sunset Magenta)
   - `Deep Obsidian` (Ultra-clean Monochrome Charcoal)

2. **🌌 60 FPS Interactive Starfield Canvas**:
   - Real-time magnetic constellation particles that gravitate and link to your cursor.
   - Dynamic colors linked directly to the selected theme.

3. **🔊 Web Audio API Synthesizer (Zero External MP3s)**:
   - Ultra-fast, zero-bloat audio synthesizer generating real-time futuristic clicks, hover chimes, terminal beeps, and game SFX.
   - Toggleable mute control with persistent `localStorage` preference.

4. **💻 AryanOS Interactive CLI Terminal**:
   - Built-in terminal emulator with commands: `help`, `about`, `skills`, `projects`, `contact`, `theme <name>`, `matrix`, `sound`, `cat resume.txt`, and secret easter eggs like `sudo hire`!

5. **⚡ Spotlight Command Palette (`Ctrl + K` / `Cmd + K`)**:
   - Instant spotlight navigation across sections, theme switching, resume requests, sound toggles, and confetti celebrations.

6. **🤖 AryanBot - Interactive AI Portfolio Assistant**:
   - Floating AI companion widget ready to answer recruiter questions about your skills, architecture principles, and contact details with pre-populated prompts.

7. **🎮 The Arcade - "Space Dodger" Retro Mini-Game**:
   - Built-in playable browser arcade game with keyboard controls (`A`/`D` or Arrow keys) and touch controls for mobile.
   - High score tracker persisted locally with celebratory confetti upon beating high scores.

8. **💎 Bento Grid Project Showcase with 3D Tilt**:
   - Dynamic 3D perspective tilt reacting to mouse position.
   - Deep-dive architectural case study modal with benchmark metrics.

9. **🎉 Interactive Contact Hub**:
   - Real-time validation, character counter, celebratory confetti cannon, and 1-click email copy with audio chime.

## 🛠️ Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```

## ⚙️ How to Personalize Your Information

All your personal details, project case studies, skills, experience, and social links are kept in a single, clean configuration file:

👉 [src/data/portfolioData.ts](file:///d:/project/portfolio/src/data/portfolioData.ts)

You can customize:
- `name`, `title`, `roles`, `email`, `location`
- Social profiles (`github`, `linkedin`, `twitter`)
- Skills list, proficiencies, and categories
- Featured projects, benchmarks, and live demo links
- Work history and career milestones
